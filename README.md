> An NLP-based SMS spam classifier using Naive Bayes & TF-IDF vectorization, achieving **97%+ accuracy** on the UCI SMS Spam Collection dataset.

---

## 🎯 Model Performance

| Metric | Score |
|---|---|
| Accuracy | 97%+ |
| Precision | High |
| Recall | High |
| Algorithm | Multinomial Naive Bayes |

---

## ✨ Features

- 🧠 **TF-IDF Vectorization** — Converts raw SMS text into numerical features
- 🎯 **Naive Bayes Classifier** — Fast, accurate probabilistic classification
- 🧾 **Data Preprocessing** — Tokenization, stopword removal, stemming
- 📊 **Evaluation Metrics** — Confusion matrix, classification report, accuracy score
- 📊 **Visualizations** — Word clouds for spam vs. ham messages

## 🚀 Getting Started

### Prerequisites
```bash
pip install pandas numpy scikit-learn nltk matplotlib seaborn jupyter
```

### Run the Notebook

```bash
# Clone the repository
git clone https://github.com/Matam-Rohith/SMS-spam--detection-.git

cd SMS-spam--detection-

# Launch Jupyter
jupyter notebook
```

Open the `.ipynb` file and run all cells.

## 📊 Dataset

- **Source:** [UCI SMS Spam Collection Dataset](https://archive.ics.uci.edu/ml/datasets/SMS+Spam+Collection)
- **Size:** 5,574 SMS messages labeled as spam or ham
